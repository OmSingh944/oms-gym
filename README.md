# 🏋️ OMS Gym

OMS Gym is a responsive gym website built using **HTML and CSS**.
The project focuses on creating a clean, modern, and user-friendly gym website layout.

## 🚀 Features

* 🏠 Home section
* 💪 About Gym section
* 🏋️ Services / Programs section
* 👨‍🏫 Trainers section
* 📞 Contact section
* 📱 Responsive design
* 🎨 Modern UI using CSS
* ✨ CSS animations and effects

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
